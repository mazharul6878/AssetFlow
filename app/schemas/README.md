# Room Exported Schemas Directory

This directory stores the official, immutable Room schema JSON artifacts generated by KSP during compilation.

- `com.example.data.offline.OfflineSyncDatabase/2.json`: Canonical Room Version 2 schema export for `OfflineSyncDatabase`.
- `2.json`: Copy of canonical Version 2 schema export for direct reference.

## Historical Note on Version 1
Room schema export was disabled (`exportSchema = false`) prior to Phase 2.3.5B. Consequently, no authentic Version 1 JSON schema was retained. As governed by `docs/DATABASE_MIGRATION_GOVERNANCE.md`, Version 1 remains unsupported and fails closed to prevent data loss.
